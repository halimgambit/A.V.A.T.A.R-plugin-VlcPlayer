# VlcPlayer
Plugin permettant de contrôler le lecteur multimédia VLC depuis A.V.A.T.A.R. et de lire des films ou séries stockés dans un répertoire vidéo local.

- This plugin is an add-on for the [A.V.A.T.A.R](https://avatar-home-automation.github.io/docs) framework. 

 ## 🎯 Usage
Fonctionnalités

▶️ Lecture de films et vidéos
Recherche automatique dans le répertoire vidéo configuré.
Parcours récursif des sous-dossiers.
Formats supportés :
.mp4 .mkv .avi .mov .m4v

📺 Lecture de séries
Recherche par nom de série.
Reconnaissance de la saison.
Reconnaissance de l'épisode.
Compatible avec différents formats de nommage (S01, Saison 01, E01, etc.).

⏯️ Contrôle de la lecture
Lecture, Pause, Reprise, Arrêt, Ferme VLC.
🔊 Contrôle du volume
Réglage du volume par commande vocale.
Valeur comprise entre 0 et 100 %.
Conversion automatique vers l'échelle de volume utilisée par VLC.

## Multi-room

The VlcPlayer plugin is fully multi-room.

## Multi-language

The VlcPlayer plugin relies solely on the system's available languages.
